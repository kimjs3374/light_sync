# Light-Sync ERP 메인 대시보드 리팩토링 및 UI/UX 고도화 기획안

## 1. 개발 목표 (Core Concept)
기존의 단순 데이터/테이블 나열식 레이아웃을 전면 폐기한다. 
새로운 대시보드는 전사 직원이 '전체 업무 흐름'과 '지금 당장 해야 할 일'을 0.5초 만에 직관적으로 파악할 수 있는 **"실행 중심의 지휘소(Operation Command Center)"** 형태로 재구축한다.
- **핵심 키워드**: 신속성(Speed), 명확성(Clarity), 업무의 연결성(Flow)

## 2. 기술 스택 (Tech Stack)
- **Backend**: Python / Flask
- **DB / ORM**: Supabase (PostgreSQL) / SQLAlchemy
- **Frontend**: HTML5 / CSS3 / Bootstrap 5 / Vanilla JS / Jinja2 템플릿 엔진

## 3. 전체 화면 레이아웃 (Grid System)
화면은 크게 3가지 논리적 영역으로 분할한다. (데스크톱 `lg` 기준)
1. **Top Banner (100%)**: 최상단 전광판
2. **Left Main Area (70%)**: 지표 요약 및 메인 워크플로우
3. **Right Sidebar Area (30%)**: 캘린더 및 실시간 타임라인 피드

## 4. 상세 영역별 UI/UX 명세

### [영역 A] 필수 전광판 (Global Alert Ticker)
- **위치**: 네비게이션 바 바로 아래, Width 100%.
- **기능**: 관리자 공지나 긴급/이슈 사항 표시.
- **UI 디테일**: 
  - Bootstrap `alert` 컴포넌트를 응용.
  - 텍스트가 가로로 부드럽게 흐르는 롤링(Marquee) 효과 적용.
  - '긴급 건'이 포함될 경우 배경에 붉은색 펄스(Pulse) 애니메이션을 은은하게 적용하여 시선 집중.

### [영역 B] 직관적 KPI 요약 카드 (4-Column)
- **위치**: 좌측 메인 영역 최상단. (`row row-cols-1 row-cols-md-4`)
- **기능**: ERP의 핵심 지표 4가지 시각화.
  1. 전체 진행 중 현장 (Total)
  2. 납품 임박 (7일 이내) -> **[Red 숫자 강조]**
  3. 자재/생산 대기 및 지연 -> **[Yellow 숫자 강조]**
  4. 미해결 이슈 로그 -> **[Red 숫자 강조]**
- **UI 디테일**: 
  - 각 카드는 `border-left` 속성을 두껍게 주어 상태 색상(Red, Yellow 등)을 표시.
  - 화려한 배경색보다는 화이트 톤의 깔끔한 카드 디자인과 가벼운 그림자(`shadow-sm`) 사용.

### [영역 C] 파이프라인 워크플로우 보드 (Flow Tracking - 핵심)
- **위치**: KPI 카드 바로 아래.
- **기능**: 영업 -> 자재 -> 생산 -> 납품으로 이어지는 공정의 흐름을 선형(Linear) 프로세스로 시각화.
- **UI 디테일**:
  - 단순 표가 아님. 각 부서를 원형 또는 박스형 노드(Node)로 디자인하고, 화살표(`->`)나 진행 선(Line)으로 서로 연결된 느낌을 부여.
  - 각 단계 노드 안에는 현재 머물러 있는 **'건수'**를 뱃지(Badge)로 표시.
  - **병목 시각화**: 특정 단계에 지연 건수(예: 미입고, 생산지연)가 있다면 뱃지를 `text-bg-danger`로 강하게 깜빡이게(Blink/Pulse) 처리.

### [영역 D] "오늘의 할 일" 액션 리스트 (Progressive Disclosure)
- **위치**: 워크플로우 보드 아래 (좌측 영역의 하단부).
- **기능**: 로그인한 사용자가 당장 처리해야 할 구체적인 이슈 리스트. (납기 임박, 협의 미완료, 배정 대기 등)
- **UI 디테일**:
  - Bootstrap `nav-tabs` 구조 적용 (영업 / 자재 / 생산 / 납품 탭).
  - 리스트 항목은 테이블 형태가 아닌 **카드 리스트(List Group)** 형태 권장.
  - 한 줄에 너무 많은 글자를 넣지 말고, 핵심 정보(현장명, 기한)와 상태를 나타내는 **'요약 칩(Badge/Chip)'**을 우측에 배치.
  - 즉각적인 행동을 유도하는 **'바로가기'** 또는 **'처리하기'** 버튼을 항목마다 반드시 포함.

### [영역 E] 캘린더 & 라이브 피드 (Right Sidebar)
- **위치**: 화면 우측 30% 영역. (`col-lg-4`)
- **상단 (납품 캘린더)**: 미니 달력 형태로, 납품 일정이 있는 날짜에 점(Dot) 마커 표시.
- **하단 (History Log 타임라인)**: 
  - 실시간 업무 변경 및 코멘트 이력을 수직 타임라인(Vertical Timeline) 형태로 구현.
  - 스크롤이 무한히 길어지지 않도록 `max-height`를 설정하고 `overflow-y: auto`를 적용. (메인 화면의 스크롤과 분리)
  - '이슈'나 '긴급' 키워드가 포함된 로그는 배경을 미세하게 붉은 톤으로 강조.

## 5. 시각적 가이드라인 (Color & Design System)
신호등 체계를 엄격하게 지켜 인지 속도를 높인다.
- **🚨 긴급/이슈 (Urgent)**: `danger` (#DC3545) - 납기 도과 위험, 결품, 에러
- **⚠️ 지연/주의 (Warning)**: `warning` (#FFC107) - 일정 지연 조짐, 미입고
- **✅ 완료/통과 (Success)**: `success` (#198754) - 정상 출고, 생산 완료
- **▶️ 정상 진행 (Normal)**: `primary` (#0D6EFD) - 현재 진행 중

## 6. 프론트엔드 개발자(AI) 행동 지침
1. 기존의 투박한 HTML 테이블 위주의 코드는 과감히 삭제하고, 위 명세에 맞춘 세련된 Bootstrap 5 뼈대를 새로 작성할 것.
2. Jinja2 템플릿 변수 처리는 백엔드에서 데이터(`projects`, `urgent_count`, `history_logs`, `notices` 등)를 넘겨준다고 가정하고 `{{ }}` 및 `{% for %}` 문법을 적재적소에 배치할 것.
3. CSS 애니메이션(전광판 롤링, 워크플로우 보드의 펄스 효과, 타임라인 디자인 등)은 `<style>` 태그에 직접 구현하여 포함할 것.
4. 모든 컴포넌트는 여백(`padding`, `margin`)을 넉넉히 주어 답답하지 않게 디자인할 것.
