## 1. 현황 분석

### 1.1 현재 업무 흐름 (AS-IS)
```
영업부: 협의완료 (ERP status_sales 변경)
  → 구두로 관리부에 "자재 확인해서 발주해달라" 요청
  → 구두로 생산부에 "제작 시작해라" + 도면 전달
  → 도면 필요 품목은 영업부가 직접 메일로 가공발주
  → 워크보드에 기록하지만, 주간회의에서 다시 확인
```

### 1.2 기존 시스템 자산
- `status_sales`: 계약확인 → 상세협의중 → 협의완료
- `status_admin`: 자재확인중 → 발주진행중 → 발주완료 → 입고진행중 → 입고완료
- `status_prod`: 자재대기중 → 생산대기중 → 생산중 → 생산완료
- `CONTRACT_ITEM_SPEC_SCHEMA`: 품목별 협의 스펙 정의 완료
- `build_action_tabs()`: 대시보드 "오늘의 할 일" 4탭 (영업/자재/생산/납품) 이미 존재
- 도면 필요 품목: 조명타워, 철제가로등주, 스텐가로등주 등 5종 정의됨

### 1.3 핵심 문제
현재 `build_action_tabs`는 **모든 미완료 건을 부서별로 보여줌**. 그러나:
1. 관리부 자재탭에 **협의도 안 된 건**까지 뜸 → 노이즈
2. 생산부 생산탭에도 **협의 미완료 건**이 섞여 있음
3. 영업부 **가공발주 필요** 건이 별도 표시 안 됨
4. **협의완료 시점**에 알림이 없어서 구두 전달에 의존

## 2. 목표 (TO-BE)

### 2.1 핵심 변경
`build_action_tabs()`를 개선하여 **협의완료 기준으로 할일을 분리** 표시:

| 부서 | 탭 | 표시 조건 | 의미 |
|------|-----|----------|------|
| 영업부 | 영업 | `status_sales != '협의완료'` | 협의 진행 필요 (기존 동일) |
| 영업부 | 가공 | `status_sales == '협의완료'` + 도면 품목 + 미발주 | **신규**: 가공발주 필요 |
| 관리부 | 자재 | `status_sales == '협의완료'` + `status_admin != '입고완료'` | 협의 끝난 건만 표시 |
| 생산부 | 생산 | `status_sales == '협의완료'` + `status_prod != '생산완료'` | 협의 끝난 건만 표시 |
| 공통 | 납품 | 기존 동일 | 납품 관련 (변경 없음) |

### 2.2 부서별 로그인 시 자동 필터링
`session.user_group`을 활용하여 기본 활성 탭 자동 선택:
- 영업부 → 영업탭 기본
- 관리부 → 자재탭 기본
- 생산부 → 생산탭 기본

### 2.3 알림 연동 (선택)
`notification_service`를 활용해 협의완료 시 관리부/생산부에 알림 생성 가능.
단, 1단계에서는 대시보드 표시만 구현하고 알림은 2단계로.

---

## 3. 구현 범위

### 3.1 1단계: 대시보드 할일 필터 개선 (이번 작업)

#### 3.1.1 `build_action_tabs()` 수정
- 자재탭: `status_sales == '협의완료'` 조건 추가 (협의 안 된 건 제외)
- 생산탭: `status_sales == '협의완료'` 조건 추가 (협의 안 된 건 제외)
- 가공탭 신규 추가: 도면 필요 품목 + 협의완료 + 가공 미발주

#### 3.1.2 대시보드 탭 UI 수정
- `action_tab_meta`에 '가공' 탭 추가
- 부서별 기본 활성 탭 자동 선택

#### 3.1.3 KPI 칩 추가
- "협의완료 대기 N건" (협의완료 후 자재/생산 미착수 건)

### 3.2 2단계: 알림 연동 (향후)
- 협의완료 시 자동 알림 생성
- 관리부/생산부 알림 목록에 표시

### 3.3 제외 범위
- 영업관리 → 협의관리 이름 변경 (별도 작업)
- 자재관리 재구성 (별도 작업)
- SUPERBOM 연동 (별도 작업)
