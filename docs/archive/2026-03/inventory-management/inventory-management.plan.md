# 재고관리 (Inventory Management) 계획서

> **Summary**: 품목 마스터 기반 재고 실사, 가용재고 확인, 재고회전율, 재고금액 관리 시스템
>
> **Project**: Light-Sync ERP
> **Author**: CTO Lead
> **Date**: 2026-03-19
> **Status**: Draft

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| **문제** | 현재 재고는 Item.stock_qty/reserved_qty에 숫자만 존재하며, 실재고 대비 시스템재고 검증이 불가능하고 재고 가치(금액)와 회전율을 파악할 방법이 없음 |
| **해결** | 재고실사 기록/차이분석 테이블 신설, 가용재고 대시보드, 재고회전율 기간별 산출, 재고금액(단가x수량) 자동 집계 시스템 구축 |
| **기능/UX 효과** | 한 화면에서 전체 재고현황(총재고/예약/가용/금액) 확인, 실사 시 모바일에서 품목 스캔 후 수량 입력, 차이 자동 계산 |
| **핵심 가치** | "재고는 다 돈" -- 재고를 금액 기반으로 관리하여 과다재고/부족재고를 사전 감지하고 자금 효율성 향상 |

## 1. 개요

### 1.1 목적

LED 조명 제조회사(매그나텍)의 자재 재고를 체계적으로 관리하여:
- 실재고와 시스템재고의 차이를 주기적으로 확인/조정
- 가용재고(총재고 - 예약수량)를 실시간 파악
- 재고회전율로 자재 운용 효율성 측정
- 재고 금액을 파악하여 자금 관리에 활용

### 1.2 배경

- 현재 `Item` 모델에 `stock_qty`, `reserved_qty` 필드가 이미 존재
- 입고(`Receiving`) 시 `stock_qty` 자동 증가 로직 구현됨
- 자재 예약(`handle_reserve_stock`) / 취소(`handle_cancel_reservation`) 로직 구현됨
- **부족한 점**: 실사 기록 없음, 재고 변동 이력 없음, 회전율/금액 분석 없음

### 1.3 관련 모듈

- `modules/models/entities.py` -- Item (stock_qty, reserved_qty)
- `routes/receiving.py` -- 입고 시 stock_qty 증가
- `modules/services/material_actions.py` -- 예약/취소
- `routes/item.py` -- 품목관리, 재고 매칭 도구
- `routes/bom.py` -- BOM 소요자재 계산

## 2. 범위

### 2.1 포함 (In Scope)

- [ ] **재고 현황 대시보드** -- 전체 재고 요약 (총재고, 예약, 가용, 금액)
- [ ] **재고실사** -- 실사 회차 생성, 품목별 실사수량 입력, 차이 자동 계산, 조정 확정
- [ ] **가용재고 조회** -- 품목별 총재고/예약/가용 실시간 표시
- [ ] **재고회전율** -- 기간별 출고(소비)량 / 평균재고 산출
- [ ] **재고금액** -- 품목별 최근 단가 x 재고수량 = 재고자산 금액
- [ ] **재고 변동 이력** -- 입고/출고/조정/예약 등 모든 변동 트래킹
- [ ] **저재고 알림** -- 안전재고 이하 품목 경고 표시

### 2.2 제외 (Out of Scope)

- 창고별 관리 (단일 창고 기준, 추후 확장)
- 바코드/QR 스캔 연동 (별도 PDCA)
- LOT 번호 관리
- 선입선출(FIFO) / 이동평균 원가계산 (1차에서는 최근단가 기준)

## 5. 리스크 및 대응

| 리스크 | 영향도 | 가능성 | 대응방안 |
|--------|--------|--------|----------|
