## 3. Key Features

### 3.1 조달내역 목록 (`/procurement`)

- **계약 단위 그룹핑**: 동일 계약의 복수 품목을 묶어 합계 금액 표시
- **상태 뱃지**: 신규(초록) / 변경(노랑) / 취소(빨강) / 규격가격(보라)
- **검색/필터**: 계약명·수요기관·규격명 검색 + 연도·품목·상태 필터
- **행 클릭 상세**: 품목별 단가·수량·금액 테이블 + 합계행
- **동기화**: 관리자 전용 일일/벌크 동기화 버튼

### 3.2 분석 보고서 (`/procurement/report`)

- **연도 선택기**: 전체 또는 특정 연도 선택
- **전체 모드**: 품목별 현황 + 수요기관 TOP10 + 연도별 계약금액 + 월별 합계금액
- **연도 모드**: 품목별 현황 + 수요기관 TOP10 + 월별 추이 + ±1년 월별 비교
- **A4 가로 인쇄**: canvas→img 변환, Bootstrap grid 인쇄 강제

### 3.3 동기화 서비스

- **이중 검색**: 물품규격명=매그나텍 + 세부품명=스포츠조명기구
- **비최종 변경차수 자동 정리**: 동일 계약의 이전 변경차수 자동 삭제
- **Flask CLI**: `flask sync-g2b --mode daily/bulk`
- **crontab**: 매일 새벽 1시 자동 실행
