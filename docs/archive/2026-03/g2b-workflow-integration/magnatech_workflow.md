## 3. 현재 ERP 시스템과의 매핑

| 워크보드 업무 | ERP 모듈 | 상태/동작 |
|-------------|---------|----------|
| 건명/계약 접수 | 계약관리 (`contracts`) | G2B 동기화로 자동 등록 |
| 제작 요청 | 자재관리 (`material_orders`) | 자재 발주/생산 |
| 납품 일정 협의 | 납품관리 (`deliveries`) | 분할납품 일정 |
| 상차/출고 | 납품관리 | 상차 사진, 출고 기록 |
| 납품 완료 | 납품관리 | 납품 완료 처리 |
| 검수 | 납품관리 (`inspection_*`) | 검수 상태/검수조서 |
| 세금계산서 | 매출관리 (`tax_invoices`) | 세금계산서 매칭 |
| 대금 입금 | 매출관리 | 입금 확인 |
| 하자보증 | 하자관리 (`warranties`) | 자동 생성 |
| A/S 접수 | 하자관리 (`warranty_cases`) | AS 케이스 등록 |
| 납품기한 변경 | 계약관리 | `delivery_due_date` 수정 |

## 4. AI 챗봇 대화 시나리오 & MCP 연동

### 4.1 현장 진행상황 조회

**사용자**: "선소테마정원 어떻게 되고 있어?"

**AI 동작**:
1. `search_projects("선소테마")` → 현재 ERP 계약 정보
2. `search_archive("선소테마")` → 과거 워크보드 진행 이력
3. `get_archive_post_detail(post_id)` → 댓글 타임라인

**응답 구조**:
```
[현장 정보]
- 계약명: 여수 선소테마정원 조성사업(전기) - LED조명기구
- 발주처: 전라남도 여수시
- 계약금액: 20,416,000원 (2건)
- 납기: 2026-03-17 (4일 경과)
- 수금: 미청구

[진행 이력] (워크보드)
- 2025-10-31 이지훈: 계약 접수 (LED보안등 22EA, 철제가로등주 22EA, 베이스커버 22EA)
- 2026-03-12 이지훈: 벤투스 가로등주 출고
- 2026-03-12 이지훈: 납품완료

[필요 조치]
→ 납품은 완료됐으나 세금계산서 미발행 상태
→ 매출/수금 → 미청구 계약 탭에서 세금계산서 매칭 필요
```

### 4.2 미청구 현장 확인

2. 납기 경과 건 우선 표시

**응답 구조**:
```

1. 익산시 보조야구장 (1,280일 경과) - 부분입금
2. 장성군 청운동 도로개설 (1,176일 경과)
3. 김해시 진영공설운동장 (318일 경과)
...

[이번 달 납기 도래] 14건
→ 납품 완료 후 세금계산서 발행이 필요한 건들입니다
```

## 6. AI 응답 원칙

### 6.1 응답 구조 표준

1. **현장 기본 정보** (계약명, 발주처, 모델, 수량, 금액)
2. **현재 상태** (수금상태, 납품상태, D-Day)
3. **진행 이력** (워크보드 타임라인)
4. **필요 조치** (다음에 해야 할 일 제안)

### 6.2 상황별 자동 판단

| 조건 | 판단 | 제안 |
|------|------|------|
| 납품완료 + 미청구 | 세금계산서 미발행 | "세금계산서 발행이 필요합니다" |
| 납기 경과 + 미납품 | 납품 지연 | "발주처에 일정 확인이 필요합니다" |
| 입금완료 + 하자보증 없음 | 보증 누락 | "하자보증 등록이 필요합니다" |
| 하자보증 30일 이내 만료 | 보증 만료 임박 | "하자보증이 곧 만료됩니다" |
| A/S 접수 + 미처리 | A/S 미완료 | "현장 방문 일정을 잡아야 합니다" |
| 부분입금 | 잔금 미수령 | "잔금 {금액}원 청구가 필요합니다" |

### 6.3 관련 현장 연결

동일 발주처/지역/공사명으로 여러 계약이 있을 수 있으므로:
- 검색 시 관련 계약 모두 표시
- 변경계약 관계 표시
- 동일 공사의 품목 분리 발주 통합 표시

## 7. 데이터 흐름 요약

```
[G2B 나라장터]                    [국세청 홈택스]
      ↓ API 동기화                      ↓ 엑셀 임포트
[g2b_procurements] ──→ [contracts] ←── [tax_invoices]
                              ↓                ↓
                        [deliveries]     [warranties]
                              ↓                ↓
                      [warranty_cases]   [certifications]

[카카오워크 워크보드]
      ↓ SQLite 이관
[archive_posts/comments] ──→ MCP search_archive
```

**핵심**: 모든 데이터가 `g2b_contract_no`로 연결됨
- G2B 조달내역 → 계약 생성 (g2b_contract_no)
- 세금계산서 비고 → G2B 번호 파싱 → 계약 매칭
- 계약 매칭 → 입금확인 → 하자보증 자동 생성
- 과거 워크보드 → 키워드 검색으로 진행 이력 참조
