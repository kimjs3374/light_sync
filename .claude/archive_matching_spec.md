## 2. 매칭 로직 (4단계 순차 적용)

### 2-1. 건명 추출

워크보드 본문에서 건명을 추출. 79%가 표준 양식:
```
건명 : {G2B 계약명}
계약일자 : YYYY/MM/DD
납품기한 : YYYY/MM/DD
```

추출 우선순위:
1. `건명 :`, `건 명 :`, `현장명 :`, `계약명 :` 뒤의 텍스트
2. 못 찾으면 본문 첫 줄 (최대 80자)
3. `납품`, `출고`, `상차` 키워드 포함 줄도 후보에 추가

### 2-2. 유사도 매칭 (SequenceMatcher)

건명 후보 vs `contracts.contract_name` 전체 비교
- `SequenceMatcher.ratio()` 기준
- 임계값: 0.5 이상이면 매칭 (1차)

### 2-3. 포함 관계 매칭

건명이 3글자 이상이고 계약명에 포함되면 매칭 (score 0.8)
- "양양공항" → "양양공항 조명탑 등기구 구매" 매칭
- "충북대학교" → "대운동장 시설보수 전기공사 관급자재" 매칭

### 2-4. 키워드 교집합 매칭

본문에서 한글 2글자 이상 단어 추출 → 계약명 단어와 교집합 비율
- `re.findall(r'[가-힣]{2,}', text)`
- 교집합 / max(본문단어, 계약명단어) 비율
- 임계값: 0.3 이상이면 매칭

### 최종 score = max(유사도, 포함관계, 키워드교집합)
