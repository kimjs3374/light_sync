대화형 ERP 설계 목업

Slack/Discord 구조로 흘러가는 대화에서 봇이 ERP 데이터를 추출·확정·기록하는 화면 설계 시안 3종.

04 ★ 추천
기존 ERP + 채팅 통합 시뮬레이터 (인터랙티브)
실제 다크 사이드바 ERP 위에서 3가지 통합 모드를 토글로 비교 — A 글로벌 도크 · B 전용 풀스크린 · C 현장 임베드. 가장 먼저 보세요.
01
3-Pane 풀스크린 레이아웃
좌(채널) · 중(메시지 스트림) · 우(컨텍스트 패널). 모드 B의 확대 상세.
03
ERP 환자차트 ↔ 채팅 통합 (상세)
현장 상세 페이지의 통합 타임라인 + 채팅 사이드바. 모드 C의 확대 상세.
